```
  └────────────────────────────────────────────────────────────────────────┘
```

### Visual Style Rules
1. **Never a static frame:** Every text element has continuous micro-motion: either a staggered spring reveal, a continuous subtle scale float (1.0 $\rightarrow$ 1.04), or parallax depth.
2. **Glassmorphism Containers:** Text cards and category tags sit inside translucent glass containers (`background: rgba(255,255,255,0.05); backdrop-filter: blur(20px); border: 1px solid rgba(255,255,255,0.12)`).
3. **Instagram UI Safe Zone Compliance:**
   - Top Header Area: 260px buffer (clear of Instagram search & audio badges).
   - Bottom UI Area: 360px buffer (clear of username, caption preview, like/comment buttons, and scrubber bar).
   - Horizontal margins: 60px padding on left and right borders.

# Phase 3: Animation & Motion Graphics Architecture

*Every animation is mathematically defined using Remotion's `spring()` and `interpolate()` physics.*

* **Text Staggering:** Strings split into individual words/characters. Each word has an offset of 3 frames, entering with `spring({ damping: 12, stiffness: 140 })`.
* **Keyword Power Stamp:** Highlight words (**BUILD, CREATE, INNOVATE, ZERO TO SCALE**) scale from 1.6 down to 1.0 with a high-speed spring bounce, accompanied by an instantaneous screen flash (white overlay opacity 0.2 $\rightarrow$ 0 in 3 frames) and a subtle chromatic aberration glitch.
* **3D Book Cover Reveal:** Scene 5 renders a CSS 3D transformed perspective card (`perspective: 1200px; rotateY(-18deg); rotateX(6deg)`), slowly rotating towards the camera (`rotateY(0deg)`) while a radial specular light flare traverses the surface from left to right.
* **Camera Depth of Field:** Background images zoom subtly (`scale: 1.0` to `scale: 1.12`) over the course of each scene, with foreground text floating in opposite horizontal vectors for parallax separation.

# Phase 5: Multi-Platform Export & Adaptation Specs

### Vertical Primary Format (Instagram Reels / YouTube Shorts / TikTok)
* **Dimensions:** 1080 × 1920 px (9:16 aspect ratio).
* **Frame Rate:** 30.0 fps (H.264 / AAC 320kbps).
* **Bitrate:** Target 16–20 Mbps VBR 2-pass for crisp mobile rendering without Instagram compression banding.
* **Safe Margins:** All text constrained within $Y = 260\text{px}$ to $Y = 1560\text{px}$.

### LinkedIn & Desktop Adaptation (16:9 Landscape Mode)
*Instead of stretching or cropping the 9:16 composition, use Remotion's multi-layout system:*
1. **Resolution:** 1920 × 1080 px.
2. **Left Half (45% Width):** Reserved for video/animation components (the vertical 9:16 phone mockup or 3D floating book).
3. **Right Half (55% Width):** Expands the typography into a bold presentation slide layout with larger bullet hierarchy, live terminal outputs, and persistent Kindle purchasing links.
4. **Background:** Spans the full 1920px width using ambient blurred particle glow.
