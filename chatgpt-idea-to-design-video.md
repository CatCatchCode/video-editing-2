You can use AI to create professional Instagram Reels, promotional videos, cinematic videos, educational videos, book-promotion videos, and business advertisements without manually editing everything.

Think of the process as having six stages:

1. Idea and concept: Decide what the video should communicate.
2. Scriptwriting: Generate a hook, narration, dialogue, and storyline.
3. Visual design: Create images, backgrounds, illustrations, graphics, and scenes.

1. Give Claude an idea

   Example: Create a 30-second cinematic motivational video about discipline.
2. Ask for a complete script

Act as a world-class professional video editor, cinematic director, motion graphics artist, VFX designer, animation engineer, sound designer, and senior React developer.

**Duration:** 30–40 seconds.

**Aspect Ratio:** 9:16 vertical.

**Resolution:** 1080 × 1920.

**Frame Rate:** 30 FPS.

**Export:** High-quality MP4 (H.264).

**Visual Style:** Premium cinematic, modern, minimal, dramatic and sophisticated.

- React + TypeScript.
- Remotion for video composition and animation.
- FFmpeg for rendering, audio mixing and final encoding.

- AI voice generation where configured and available.

First inspect the development environment and available tools. Install only the necessary dependencies.

Do not assume that API keys or paid services are available. If unavailable, use locally generated graphics, original animations and available assets.

- Duration.
- Background visuals.
- Main subject.
- Camera movement.
- Text animation.
- Transition.
- Sound effect.
- Voiceover.
- Lighting and color treatment.

Maintain visual consistency across all scenes.

- Ambient sound.

- Subtle cinematic risers.

Use properly licensed or original audio.

Write an engaging opening hook within the first two seconds.

Create a compelling narrative with a strong emotional progression.

Use short, impactful on-screen sentences.

Include a memorable ending and a professional call to action.

Avoid unnecessary text and generic motivational visuals.

Build the video as separate reusable React components.

Keep scenes modular and maintainable.

Use frame-accurate animation timing.

Ensure typography is readable on mobile screens.

- Text.
- Colors.
- Fonts.
- Scene duration.
- Animation speed.
- Audio.
- Video resolution.
